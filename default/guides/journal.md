# Complete a journal

Record the date, evidence, accounts and known amounts. Leave exactly one intended balancing monetary amount empty. Request the ordinary completion preview and inspect every proposed line, then apply through the guarded host operation. Revalidate before posting.

The example `tests/autocomplete.yaml#money-only balance needs no extra journal fields` pins the proposal. Completion is an editing operation; it does not authorize posting or establish the economic meaning of a transaction.

The selected Book copy supplies this operation. Disabling the package removes it; the engine does not silently restore a default.
