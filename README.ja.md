# IrisBooks overlays

[English](README.md) | **日本語**

YAML と CEL で記述する帳簿の定義集です。ローカルの Iris エンジンが検証・計算を行い、クラウドはファイルと参照情報を保管します。

## 初期カタログ

| パッケージ | 用途 | 公開候補バージョン |
|---|---|---|
| `default` | 仕訳の貸借補完と在庫売却の原価・損益の提案 | `2026.10.2` |
| `jp-consumption-tax` | 消費税区分、税抜金額からの税額提案、対応範囲を限定した申告計算の補助 | `2026.10.1` |
| `jp-fixed-assets` | 設備の記録、少額資産特例の確認、通年の定率法計算の補助 | `2026.10.1` |

候補版には bindings 5 が必要です。タスク、項目の定義、ガイド、実行可能な例を同梱しています。日本向けの2パッケージは個別に選択できます。家計用の勘定科目は帳簿作成プリセットが用意します。従来の `jp` は過去の結果の再現用に保持し、新規の日本向け事業用帳簿は分割後のパッケージを選択します。従来の `jp` と置き換え先を同時に選択しないでください。

## 配布と帳簿内の保管

署名付き GitHub リリースと、オフラインで導入できるエンジン同梱版で配布します。同梱対象は初期利用に必要なカタログであり、過去の全版を同梱する必要はありません。候補版は署名付きの配布物を公開するまで未公開です。対応する署名付きエンジンと公開時期を調整してください。CI も対応エンジンで実行します。

導入すると、正確なバージョンのコピーを帳簿の `config/overlay-packages/` に保存します。`config/book.yaml` で明示的に選択すると有効になり、空の選択は無効を意味します。検証・計算・過去の再現は帳簿内のコピーを読みます。地域による暗黙の有効化や、実行時のバイナリへの代替参照はありません。既存帳簿の選択は自動変更しません。

過去の結果に必要なパッケージとローカル定義の親は帳簿に保持します。選択の解除や将来の同梱対象からの除外によって削除しません。更新時は出典と記録済みの結果への影響を確認してから適用します。

適用要件、税務上の選択、証憑は利用者が確認します。検証の通過は税制の適用可否や申告書の完成を保証しません。各ガイドの対応範囲を確認してください。検証手順とファイル構成は [English README](README.md)、開発手順は [CONTRIBUTING.ja.md](CONTRIBUTING.ja.md) を参照してください。
