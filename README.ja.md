# IrisBooks オーバーレイ

[English](README.md) | **日本語**

[IrisBooks](https://irisbooks.jp) の記帳・税務ルールを、YAML と
[CEL](https://cel.dev) で定義するリポジトリです。`default/` には共通の仕訳補完を、
`jp/` などの地域パッケージには各地域のチェックと計算を置きます。
`iris` エンジンが、記録を参照する仕組みと計算機能を提供します。

| パス | 内容 |
|---|---|
| `<id>/overlay.yaml` | id、バージョン、必要なバインディングのバージョン |
| `<id>/functions.yaml` | 以下のすべてで共有する名前付きの CEL 関数 |
| `<id>/rules/` | チェック。`iris validate` が実行し、クラウドも書き込みのたびに実行します |
| `<id>/recipes/` | 計算。出力は根拠付きで記録され、再計算で照合されます |
| `<id>/completions/` | エンジンの計算機能を使い、下書き仕訳の金額と行をまとめて補完する定義 |
| `<id>/derive/` | 未入力のフィールドに `iris validate --fix` が提案する値 |
| `<id>/tests/` | 上記すべてのテストケース（入力と、期待する結果の組） |

## 共通の既定パッケージ

`default/` は、貸借を合わせる金額の補完と、先入先出法（FIFO）による売却原価・
損益の提案を定義します。対応するエンジンに同梱され、自動で使われるため、
単純な仕訳にポリシーの属性や固定バージョンを追加する必要はありません。
`default@<version>` を明示すると、そのバージョンを使います。専門パッケージや
信頼済みの帳簿ローカル定義で、同じ ID の補完ルールを置き換えられます。
詳細は [default/README.md](default/README.md) を参照してください。
初版はバインディングのバージョン3が必要です。上流へのマージとタグ公開は、
対応するエンジンのリリース後に行います。

## 帳簿がオーバーレイを使うしくみ

`iris` の各リリースには、ビルドした時点で公開済みのオーバーレイが組み込まれて
います。帳簿は検証に使うバージョンを `config/book.yaml` で固定します。この
リポジトリのタグ名が、そのまま固定に書く値になります。

```yaml
region: JP
overlay: jp@2026.09.1   # = このリポジトリのタグ jp@2026.09.1
```

固定が勝手に動くことはなく、更新するには明示的に書き換えます。公開済みの
バージョンの中身も変わりません。レシピが計算した償却表や申告の集計値は、出どころ
として `overlay: jp@<version>` を記録します。`iris validate` はそのバージョンで
レシピを再計算し、記録された値が入力から正しく計算されたかを確かめます。

オーバーレイは**計算方法**に加えて、その計算に必要な**法定の数値**（率、
金額基準、経過措置の割合など）も持てます。数値は法令が基準にする日付（取得日、
仕入日など）ごとに定め、出典を添えます。税制改正は新しいバージョンとして出し、
改正前の日付には改正前の数値がそのまま使われます。納税者や市区町村ごとに
異なる数値（市区町村の償却資産税の税率など）はレシピのパラメータのままにし、
ユーザーの AI が調べて帳簿に記録します。

帳簿は `config/overlays/` に独自のルールやレシピを重ねられます。詳しくは
[帳簿ファイル形式リファレンス](https://irisbooks.jp/manual/ja/book-format-reference/)
にあります。ひとつの帳簿を超えて役立つ層があれば、このリポジトリへの
プルリクエストをお待ちしています。手順は [CONTRIBUTING.ja.md](CONTRIBUTING.ja.md)
にまとめています。

## テストを実行する

```sh
iris overlay test --dir jp
```

`--dir` には `iris` v0.2.0 以降が必要です（[インストール](https://irisbooks.jp/start)）。
CI でも、プルリクエストのたびに最新の署名付きリリースを使って同じテストを
実行します。

## 免責事項

オーバーレイは、帳簿に記録された内容をチェックし、計算します。税務上の助言では
なく、税理士の代わりにもなりません。
