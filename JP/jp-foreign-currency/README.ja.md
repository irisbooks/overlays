# 通常のドル現金の為替差損益を計算する

[English](README.md) | **日本語**

株式の売却代金を含む通常のドル現金について、本人名義口座間の移動を通じて円建ての
取得費を引き継ぎ、実現した為替差損益を株式の譲渡損益や給与と分けて計算します。
取得費には、明示的に確認した移動平均法を使います。

## 利用前に確認すること

取得費の計算方法と、指定した口座に対象となる通常のドル残高がすべて含まれていることを
確認してください。MMFへの自動振替、証拠金取引、外国税額控除、未解決の受渡時差は
対象外です。出力は申告準備資料で、申告書の提出は行いません。bindings 6に対応する
エンジンが必要です。

[公開状況とエンジンの要件](../../README.ja.md#使いたいパッケージを選ぶ)、[導入と有効化の手順](../../README.ja.md#帳簿で使う)も確認してください。
