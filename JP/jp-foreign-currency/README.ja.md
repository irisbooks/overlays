# 通常の米ドル現預金の為替差損益を計算する

[English](README.md) | **日本語**

通常の米ドル現預金（株式の売却代金を含む）について、実現した為替差損益を計算します。本人名義口座間でドルを移しても、円建ての取得費はそのまま引き継ぎます。為替差損益は、株式の譲渡損益や給与とは分けて計算します。取得費の計算には、利用者が確認した移動平均法を使います。

## 利用前に確認すること

取得費の計算方法と、指定した口座に対象となる通常のドル残高がすべて含まれていることを確認してください。MMFへの自動振替、証拠金取引、外国税額控除、未解決の受渡時差は対象外です。出力は申告準備資料で、申告書の提出は行いません。バインディング6に対応するエンジンが必要です。

[公開状況とエンジンの要件](../../README.ja.md#使いたいパッケージを選ぶ)、[導入と有効化の手順](../../README.ja.md#帳簿で使う)も確認してください。
