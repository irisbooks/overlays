# RSUの権利確定から売却・送金まで、数値ごとに使うパッケージ

[English](lifecycle.md) | **日本語**

権利確定は、両方の明細に円の金額を書き、根拠を給与の明細に書いて記録します。あとは3つのパッケージが、申告の準備に使う数値を一つずつ出します。申告書を作る本人や税理士に渡す数値です。

| 数値 | パッケージとレシピ | 内容 |
|---|---|---|
| `additional_salary_receipts`、`by_payer`、`records` | `jp-rsu.salary` | 源泉徴収票に含まれないRSUの給与収入。合計と支払者別の額です。ほかの給与と合算してから給与所得控除を適用します。 |
| `taxable_gain`、`acquisition_cost`、`remaining_allocation_cost` | `jp-securities-basis.basis` | 売った株式の譲渡損益。同じ銘柄なら、権利確定した株も購入した株も一つの平均で取得費を計算します。 |
| `realized_fx_gain` | `jp-foreign-currency.realized` | 通常のドル預金の為替差損益。売却代金のドルを円に替えたり送金したりしたときに生じます。給与や譲渡損益とは別に扱います。 |

どのパッケージも、税額の計算や申告書の作成はしません。

## パッケージを選ぶ

給与だけなら `jp-rsu` で足ります。株式を売るなら `jp-securities-basis` を、ドルを持つ・円に替える・送金するなら `jp-foreign-currency` を選択します。設定はパッケージごとにあります。[権利確定のガイド](vesting.ja.md#帳簿を設定する)と、`iris overlay guide jp-securities-basis.shares.ja`、`iris overlay guide jp-foreign-currency.cash.ja` を参照してください。`jp-rsu` を選んでも、ほかの2つは選択されません。

## 権利確定を記録する

円の金額は、株式の明細と給与の明細の両方に書きます。根拠は給与の明細だけに書きます。`event_id` は権利確定の識別子、`payer` は付与した会社、`valuation_source` は `raw/` に保存した明細書の場所です。名前は例です。

```yaml
date: 2026-05-15
status: posted
lines:
  - account: Assets:EXMP
    debit: 250005
    quantity: 10
    unit: EXMP
  - account: Income:RSU
    credit: 250005
    jp_rsu: {event_id: vest-2026-05, payer: Example Corp., valuation_source: raw/vest-2026-05.pdf}
```

株式の借方の金額が、その株の最初の取得費になります。給与として受け取った株の取得費は、給与として課税された額です。0円にはせず、あとで納める税額を足すこともしません。そのため、株式の借方と給与の貸方は同じ金額にします。金額が違う仕訳は `rsu.valuation` ルールが拒否します。給与の貸方を空けておけば、`iris journal complete` が株式の借方と同じ金額で補完します。

権利確定をどの株価と為替レートで評価するかは、パッケージは判断しません。制度ごとに確認し、明細書を保存してください。株価とレートから円の金額を iris に計算させたい場合は、[権利確定のガイド](vesting.ja.md#円建ての権利確定額を計算する)の、両方の明細に根拠を書く形を使います。

## 売却と送金を記録する

売却は、受け取った円の金額を書き、株式の貸方は空けて記録します。`iris journal complete` が帳簿価額と損益を補完します。送金には、口座間の移動・円への両替・手数料が含まれることがあります。手数料は別の明細に記録します。ドルのまま本人名義の口座間で移す場合の書き方は、`iris overlay guide jp-foreign-currency.cash.ja` で確認できます。株価や為替レートを取得するパッケージはありません。日付ごとの円の金額は、明細書から記録してください。

## 数値を出す

```sh
iris overlay recipe jp-rsu.salary --set scope_confirmed=true \
  --set income_account=Income:RSU --set from=2026-01-01 --set to=2026-12-31
iris overlay recipe jp-securities-basis.basis --set scope_confirmed=true \
  --set from=2026-01-01 --set to=2026-12-31
iris overlay recipe jp-foreign-currency.realized --set scope_confirmed=true \
  --set from=2026-01-01 --set to=2026-12-31
```

どれも結果を表示するだけです。`--apply --out filings/<名前>.md` を付けると、計算に使った入力と一緒に保存します。

## 数値例

次の1年分の取引について、3つのパッケージは次の数値を返します。

| 日付 | 取引 | 円 |
|---|---|---|
| 3月1日 | 1,000ドルを購入 | 140,000 |
| 5月15日 | 10株が権利確定 | 250,005 |
| 8月15日 | 7株が権利確定 | 190,003 |
| 8月16日 | 12株を2,200ドルで売却 | 330,000 |
| 8月18日 | 2,200ドルを送金。手数料25ドルを引かれ、残り2,175ドルを151円で円に両替 | 328,425を受取 |

| 数値 | 結果 | 計算 |
|---|---|---|
| 給与収入 | 440,008（すべてExample Corp.） | 2回の権利確定の合計 |
| 譲渡益 | 19,404 | 17株の取得費440,008円から1株25,882.8円、切り上げて25,883円。12株で310,596円 |
| 為替差益 | 5,300 | 3,200ドルの取得費470,000円から、送金した2,200ドルは323,125円。受け取った328,425円との差 |

株の取得費に証券会社のロットごとの原価を使ったり、ドルの取得費に売却代金だけを使ったりすると、異なる誤った数値になります。株式・外貨のパッケージがあるのは、この平均の計算のためです。

## 自分で確認すること

- 権利確定・売却・送金がすべて記録されているかを、証券会社と勤務先の記録で照合する。帳簿にない取引は、パッケージには見えません。
- 評価に使う株価の基準と、日付ごとのレートを確認する。
- 給与所得控除、税額、外国税額控除、申告書の作成。
- 対象外：権利確定時に納税のために売却・差し引かれる株（sell-to-cover、純額決済）、端株、NISA・特殊口座、約定日と受渡日の扱いが決まっていない売却。
