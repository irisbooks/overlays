# RSUの権利確定と追加の給与収入を記帳する

[English](README.md) | **日本語**

権利確定した株式（整数株）の円換算額を正確に計算し、仕訳の株式側の借方金額と給与側の貸方金額を同時に補完します。両方の明細に記録した権利確定の根拠が一致することを検証し、ローカルの帳簿にある全仕訳から、追加の給与収入を暦年で集計します。

確認済みの円換算額（`gross_jpy`）だけを記録した従来の仕訳も、そのまま使えます。`valuation`の入力がすべてそろっていれば金額はそこから求められるので、同じ金額を`gross_jpy`に重ねて記録する必要はありません。端数処理の方法は、利用者が明示的に指定します。計算は、パッケージ内の非公開関数で行います。

## 利用前に確認すること

対象は、株式で交付される通常の従業員向けRSUで、日本に居住して日本で勤務し、日本で源泉徴収されていない場合です。条件の全体は[操作ガイド](guides/vesting.ja.md)で確認してください。

給与の記録だけなら他のパッケージは不要です。株式の譲渡と、端数処理後の残存取得費を扱うには`jp-securities-basis`を、通常の米ドル現預金の実現差損益を扱うには`jp-foreign-currency`を、それぞれ別途選択します。対応範囲の確認と対象科目の設定は、パッケージごとに行います。`iris yearend`は、帳簿価額と、それとは別に保持する配分取得費（税務上の取得費）の両方を、翌年度へ引き継ぎます。

出力は申告準備資料です。申告書の提出や会計ビューの承認は行いません。バインディング6に対応するエンジンが必要です。

[公開状況とエンジンの要件](../../README.ja.md#使いたいパッケージを選ぶ)、[導入と有効化の手順](../../README.ja.md#帳簿で使う)も確認してください。

## タスクに沿って進める

タスク ID は `jp-rsu.vesting` です。帳簿フォルダーで次を実行します。

```sh
iris context --task jp-rsu.vesting
iris overlay guide jp-rsu.vesting.ja
```

[操作ガイド](guides/vesting.ja.md)に入力、コマンド、対応範囲を記載しています。[タスク定義](tasks.yaml)から、次のテスト例も参照できます。
