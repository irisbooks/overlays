# jp-rsu

bindings 6を必要とする未公開の`2026.10.2`ソース候補版です。
適合確認には`.github/engine.txt`に固定した公開済み・署名済みの安定版を使います。

整数株数の円換算を正確に計算し、株式の借方と給与の貸方を同時に補完します。
対応する権利確定の根拠を検証し、完全なローカル台帳から追加給与収入を暦年で集計します。
確認済みの円換算額は引き続き使えます。完全な`valuation`入力がある場合は、
同じ金額を`gross_jpy`に重ねて記録する必要はありません。端数処理を明示し、
計算はOverlay内の非公開関数で行います。

給与の記録だけなら他のパッケージは不要です。株式譲渡と端数処理後の取得費には
`jp-securities-basis`、通常の米ドル現預金の実現差損益には`jp-foreign-currency`を
独立して選択します。各パッケージで対応範囲と科目を明示します。
単一の帳簿ルートの年度繰越では、帳簿価額と別の配分取得費を引き継ぎます。

[日本語ガイド](guides/vesting.ja.md)、[既存の記帳例](tests/vesting.yaml)、
[評価計算例](tests/valuation.yaml)、[復元したワークフロー](tests/full-workflow.yaml)を参照してください。

署名済み公開パッケージではありません。出力は申告準備資料です。
名前付きビューの申告資料・年度繰越、承認済み財務世代、e-Tax送信は別のホスト開発項目です。
