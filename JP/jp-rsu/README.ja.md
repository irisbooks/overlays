# jp-rsu

未公開の`2026.10.2`候補版です。公開済みの署名付きIris v0.2.18
（bindings 5）で動作します。

確認済みの日本居住・勤務の従業員の自己申告納税という運用について、
円建てRSU仕訳を検証し、給与貸方を補完し、確定済み給与収入を暦年で
集計します。有価証券取得費パッケージへの依存はありません。
株価・為替による自動評価や有価証券・外貨の取得費計算は、必要なコア機能が
公開されるまで別の開発項目とします。汎用の在庫計算で代用しません。

[日本語ガイド](guides/vesting.ja.md)と[実行例](tests/vesting.yaml)を参照してください。
署名付きの公開版ではありません。評価額を確認し、先に帳簿を検証してください。
