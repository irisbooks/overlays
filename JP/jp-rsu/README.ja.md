# jp-rsu

未公開の`2026.10.2`候補版です。公開済みの署名付きIris v0.2.18
（bindings 5）で動作します。

確認済みの日本居住・勤務の従業員の自己申告納税という運用について、
整数株数の円換算額をオーバーレイ関数で正確に計算し、仕訳を検証して、
給与貸方の補完と確定済み給与収入の暦年集計を行います。株価・為替は係数と
小数桁数で記録し、丸め方を明示します。結果を確認して株式借方に入力してから
給与貸方を補完します。有価証券取得費パッケージへの依存はありません。

有価証券・外貨の取得費や方針に基づく翌年繰越は別の開発項目です。
汎用の在庫計算で代用しません。

[日本語ガイド](guides/vesting.ja.md)と[実行例](tests/vesting.yaml)、
[評価額の計算例](tests/valuation.yaml)を参照してください。
署名付きの公開版ではありません。入力と評価結果を確認し、先に帳簿を検証してください。
