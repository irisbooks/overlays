# 消費税の計算資料を作る

[English](filing.md) | **日本語**

このレシピは、消費税の計算補助資料を作ります。以下の対応範囲を読み、集計対象の税区分付き仕訳を証憑と照合してから `scope_confirmed: true` を指定してください。省略または `false` はエラーになります。この設定は利用者の判断を記録するもので、適用要件を自動確認するものではありません。申告書の作成・提出と会計ビューの承認は、別途行います。

## 計算前に対応範囲を確認する

どちらのレシピも、10%または8%（軽減・旧税率）の転記済み明細を集計します。旧税率5%・3%の申告計算には未対応です。`from` と `to` は前後関係が正しく、確認済みの課税期間と一致する必要があります。税込経理の金額は税込、税抜経理の金額は税抜で記録します。返品、取消、請求書の端数処理を確認してください。国税・地方税の区分、課税標準額の端数処理、その他の調整は対象外です。

本則課税のレシピは、課税売上割合95%以上かつ課税売上高5億円以下で、仕入税額の全額控除が認められることを前提にします。また、インボイスのない仕入れの相手先ごとに、経過措置の上限を超えないことが前提です。相手先別の集計や上限の検証は行いません。必要な証憑と、その課税期間に適用される上限を確認してください。2026年10月1日以降に開始する課税期間では、1億円の上限も確認します。仕入税額の一部控除、固定資産に関する調整、特例、税区分がない明細には対応していません。

インボイスのない課税仕入れの控除割合は、仕入日で切り替えます。

| 仕入日 | 控除割合 |
|---|---|
| 2023年10月1日から2026年9月30日まで | 80% |
| 2026年10月1日から2028年9月30日まで | 70% |
| 2028年10月1日から2030年9月30日まで | 50% |
| 2030年10月1日から2031年9月30日まで | 30% |
| 2031年10月1日以降 | 0% |

簡易課税のレシピには、有効な選択届出、各課税売上の事業区分1〜6（または確認済みの帳簿の既定値）、みなし仕入率の `deemed_pct` が必要です。適用する率と、複数の事業を営む場合の特例的な扱いを確認してください。有利な方式の選択は行いません。2割特例・3割特例には未対応です。これらの対応範囲に収まらない場合は、レシピを実行しないでください。

## 計算結果を確認してから保存する

`iris context --task jp-tax-classification.classify` で帳簿の税設定を確認し、`iris context --task jp-tax-filing.filing` で計算の入力を確認します。必要な固定バージョンの両パッケージを有効にしてください。`jp-tax-amount` は不要です。

次は、確認済みの課税期間が2026年1月1日から12月31日までの場合に、帳簿フォルダーで本則課税の計算結果を表示する例です。

```sh
iris overlay recipe jp-tax-filing.shouhizei-general --set scope_confirmed=true --set from=2026-01-01 --set to=2026-12-31
```

簡易課税では `jp-tax-filing.shouhizei-simplified` を使い、同じ期間・確認のパラメータに加え、適用できることを確認した `--set deemed_pct='{"1":90,"2":80,"3":70,"4":60,"5":50,"6":40}'` を指定します。実際の課税期間と入力値に置き換えてください。どちらも呼び出したときだけ計算します。

結果の表示だけではファイルを作成しません。確認した集計値を保存する場合は、同じコマンドに `--apply --out filings/consumption-tax-2026.md` を追加し、帳簿内の保存先を指定します。計算補助資料と、パッケージのバージョン、レシピ、入力値を記録します。保存後は `iris validate` で計算を再検証してください。

両モードとも `list_recipes` で CLI と同じレシピ ID と入力形式を確認し、`run_recipe(recipe=返されたID, params={...})` で結果を表示します。ID は `jp-tax-filing.shouhizei-general` と `jp-tax-filing.shouhizei-simplified` です。確認した計算補助資料を保存する場合は、`params` の外に `apply=true, out="filings/consumption-tax-2026.md"` を追加します。`out` だけでは保存しません。親モードは両方の呼び出しに `book` も必要です。[計算例](../tests/filings.yaml)、[確認項目のテスト](../tests/coverage.yaml)、[経過措置の期間別テスト](../tests/transitions.yaml)も参照できます。
