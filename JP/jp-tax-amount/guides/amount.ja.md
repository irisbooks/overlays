# 未入力の消費税額を提案する

[English](amount.md) | **日本語**

最初に `jp-tax-classification.classify` で、確認済みの課税事業者・免税事業者の区分、課税方式、経理方式を確認します。各項目は[税区分のガイド](../../jp-tax-classification/guides/classification.ja.md)で説明しています。必要な固定バージョンの両パッケージを有効にしてください。

税抜経理の帳簿では、税区分を記録した課税明細の税抜金額に税率を掛け、1円未満を切り捨てた値を、未入力の `line.tax.amount` に提案します。税込経理の帳簿には提案せず、入力済みの税額は変更しません。

帳簿フォルダーで、仕訳と検証結果の候補を確認します。

```sh
iris context --task jp-tax-amount.propose --record journals/2026-10/purchase.md
iris validate
```

パスは実際の仕訳に置き換えてください。金額の税込・税抜の扱い、請求書の端数処理、**すべての項目補完の候補**を確認してから、次を実行します。

```sh
iris validate --apply
```

`--apply` は帳簿全体の適用可能な項目補完を行います。上で確認した仕訳だけに限定する操作ではありません。ローカル MCP の `validate` は、補完を適用せずに検証します。候補を適用する場合は、CLI のコマンドを明示的に使ってください。

補完するのは税額の項目だけで、仮払・仮受消費税の仕訳明細は追加しません。転記前に、仕訳全体と必要な税額の明細を確認してください。提案を止める場合は、ほかに使うパッケージを残したうえで、有効な一覧から `jp-tax-amount` を外します。[選択の手順](../../../README.ja.md#帳簿で使う)を参照してください。申告資料の計算パッケージは不要です。[提案する場合・しない場合のテスト例](../tests/amount.yaml)も参照できます。
